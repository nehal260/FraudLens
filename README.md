# FraudLens

Card fraud detection that learns from past transactions and scores new ones.
Three models are trained and compared (Logistic Regression, Gradient Boosting,
Random Forest). The winning Random Forest is exported to the website, which
scores transactions entirely in the browser: no server, nothing uploaded.

```
FraudLens/
  ml/                      model training (Python)
    train_model.py         load data, 80/20 split, train and compare 3 models
    export_for_web.py      push the trained forest + results into the website
    generate_demo_data.py  stand-in data so you can test the pipeline
    requirements.txt
    data/                  put creditcard.csv here
    models/  artifacts/    created by the scripts
  web/                     the app (plain HTML, CSS and JavaScript)
    index.html
    css/style.css
    js/                    engine, charts and one file per tab
    data/                  generated by export_for_web.py
    assets/                favicon + sample_transactions.csv
  docs/
    PROJECT_NOTES.md       the project explained in plain words
```

## Run the website
Open `web/index.html` in a browser. That's it (internet is only needed for the web fonts).

## Use the real data (important)
The site ships in **demo mode**: its numbers come from synthetic stand-in data,
and a banner says so. To switch to the real results:

1. Download `creditcard.csv` (Kaggle: "Credit Card Fraud Detection", ULB) into `ml/data/`.
2. ```
   cd ml
   pip install -r requirements.txt
   python train_model.py          # a few minutes; Gradient Boosting is the slow one

   ```
3. Reload `web/index.html`. The banner disappears and every number, chart and
   score now comes from your real models.

(`python train_model.py --demo` and `python export_for_web.py --demo` rebuild the demo version.)

## What's in the app
| Tab | What it does |
|---|---|
| Overview | The project in one page |
| Check a Transaction | Score one transaction, see which columns drove the score ("why"), tweak columns in a what-if sandbox, reveal the true label |
| Check Many (CSV) | Drop a file, score every row, filter, download flagged rows; marks itself if a `Class` column exists |
| Live Monitor | Held-back transactions stream through the model like a fraud desk |
| Model Results | Confusion matrices, precision/recall/F1, precision-recall curve, threshold lab, cost simulator, model card |
| About the Data | "Find the bad apples" basket, the lazy model, amount/time charts, column explorer |

## Notes
- The in-browser forest is the same trained model (100 trees, max depth 12); scores match scikit-learn to ~1e-6.
- `V1..V28` are scrambled (PCA) in the public dataset, so the app uses sample transactions rather than free typing.
- Data: ULB / Worldline credit card fraud dataset. Models: scikit-learn.
